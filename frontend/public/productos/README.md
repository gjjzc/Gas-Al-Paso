# Imágenes de productos

Seis archivos WebP de menos de 200 KB cada uno, servidos bajo `/productos/` y utilizados directamente por la semilla del catálogo. Conservan los nombres `balon-5kg`, `balon-11kg`, `balon-15kg`, `balon-45kg`, `regulador` y `manguera`.

Procedencia, conversión y tamaños: [créditos](../../../docs/creditos-imagenes.md).
